# 个人作品集与排版编辑器

## GitHub 与 Cloudflare Pages 发布

仓库：<https://github.com/indigo-yq/My-Portfolio>，发布分支为 `main`。

在 Cloudflare Pages 中连接此仓库，填写：

| 设置 | 值 |
| --- | --- |
| Production branch | `main` |
| Framework preset | `None` |
| Build command | `node scripts/build.cjs` |
| Build output directory | `dist` |
| Root directory | 仓库根目录（留空） |

构建不需要安装项目依赖。脚本读取已保存的 `data/project.json` 和素材，使用与编辑器导出相同的网站运行代码，生成包含所有页面的静态网站。公网展示无需运行 `server.cjs`，编辑器仍在本机使用。

本机修改后，等待编辑器显示“已自动保存”，再运行 `node scripts/build.cjs` 检查构建，然后执行 `git add .`、`git commit -m "Update portfolio"`、`git push`。Cloudflare Pages 会在推送后重新部署。`dist/` 是构建结果，无需提交。

Git 不收录 `.preview/`、`backups/`、数据备份和日志。`网页内容/` 与 `联系方式/` 的原始文件留在本机；网站及编辑器使用的素材副本保存在仓库的 `data/assets/` 与 `assets/`，克隆后可以继续编辑和发布。后文依赖原始文件、备份或 `.preview/` 清单的本机验证脚本，需要保留这些本地文件。

部署参数参考 [Cloudflare 静态 HTML 文档](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/)。

双击 **启动编辑器.cmd**。浏览器打开 `http://127.0.0.1:4174/editor/`，服务在后台运行；下次双击会打开同一份项目。网站预览在 `http://127.0.0.1:4174/`。无需安装项目依赖，启动器会自动查找当前电脑已有的 Node.js。

## 编辑

1. 左侧切换页面；点 **＋** 新建，点页面旁 **✎** 重命名。初始分类名称会同步到首页分类入口和网站导航，项目页改名会同步封面标题；直接修改该入口文字后，它成为独立文案。
2. 上传 PNG、JPG、WebP、SVG、GIF 或 MP4，点击素材即可添加。透明图片保留透明背景。PSD、AI 请先导出网页图片。
3. 拖动元素移动，四角手柄缩放，顶部圆形手柄旋转。图片默认等比例缩放；按住 Shift 可改变比例，旋转时按住 Shift 以 15° 对齐。
4. 双击文字直接编辑，或在右侧修改内容、字体、字号和颜色。上方 **中 / EN** 切换要编辑的语言。
5. 图层列表上方位于前景；上下拖动排序。眼睛按钮控制当前视图是否显示，锁定后不可移动或删除。Delete 删除，Ctrl+Z 撤销，Ctrl+Shift+Z 重做。每页最多保留 80 步历史，历史不跨重启保存。
6. **桌面 / 手机** 共用元素、文字和素材，分别保存位置、尺寸、旋转、字号和可见性。删除元素会移除两个视图的实例，素材原件仍在素材库。
7. 右侧 **预设互动** 提供悬停、滚动入场、图形光标、访客拖动、拼贴动态、图片演示轮播、作品墙轮播和点击放大；**点击后** 可以跳页面、跳首页区块、打开联系或外部网址。演示轮播可以勾选图片和 MP4，按勾选顺序播放；没有指定列表时使用当前页面的图片，排除设置中的微信二维码。
   首屏 **DESIGN 六种拖尾** 可编辑大标题、背景词语并勾选图片素材，背景通过“填充”更改。点“预览”后切换六种效果、移动鼠标体验；手机横向轻扫产生图片，竖向滑动继续滚动页面。作品墙轮播同样可勾选图片，按勾选顺序循环。首页第三模块每张作品图停留 3 秒，仅使用所选作品素材，不播放肖像或自我介绍图；其他演示和作品墙轮播默认每张图停留 5 秒，手动切换和恢复播放后重新计时。拖尾和离线导出均不依赖外部动画库或图片网址。
8. 分类页顶部 **＋ 项目** 会复制一个可替换项目模板，并生成独立详情页。选择封面或同项目图层，右侧修改中英分类名称，预览中的筛选会自动更新；封面图用“替换素材”更换。详情图片和说明在左侧同名项目页编辑，也可继续添加素材与文字。新增项目占用一个页面，项目最多 50 个页面。
9. 画布下端的手柄调整页面长度。使用 **个人资料** 设置中英署名、邮箱、微信号和二维码。默认问候与版权文字会跟随署名，直接编辑这两处文字可改为自定义内容。

预览与导出使用同一套网站渲染代码。视频在可视区域内循环，离开后暂停；网站提供暂停动态按钮，尊重系统减少动态的偏好。

## 保存与多窗口

编辑会自动保存到 `data/project.json`，上传原文件保存在 `data/assets/`。顶部显示 **已自动保存** 后再关闭。断线时修改留在窗口内，恢复连接后重试；显示未保存时不要关闭窗口。

多个窗口共用本机服务的最新数据。不同页可同时编辑；同一页一个窗口持有编辑权，其他窗口实时查看，点击 **接管编辑** 可切换。接管使用服务端最新版本，并清空本窗口的撤销历史。旧窗口尚未保存的内容不会覆盖新窗口；应先等待保存完成再接管。

关闭浏览器不停止服务；电脑重启后再次双击即可恢复。编辑器仅监听本机，不提供跨电脑协作。

## 导出、恢复和发布

- **完整项目备份**：下载 `portfolio.folio.json`，包含所有页面、两套布局、文字、互动设置和原素材。导入后继续编辑。单素材上限 50MB，导入项目上限 180MB。
- **可发布网站 ZIP**：解压 `portfolio-website.zip`，打开其中 `index.html` 可离线浏览；发布时上传整个解压目录。所有页面通过网址中的 `#page=…` 切换。
- 导入会替换当前项目，并先保存 `data/backup-时间戳.json`。该本地备份引用原文件，必须和 `data/assets/` 及原 `assets/` 一起保留；便于搬迁的完整备份应使用编辑器的项目导出。
- 旧版本源文件保存在 `legacy-site/`，旧占位资源保留在 `assets/`。旧版本文件仅作备份，不再用于新编辑器。

需要手动启动时，在当前目录运行 `node server.cjs`。环境变量 `PORT` 可以修改端口，`PORTFOLIO_DATA` 可以选择独立数据目录。

## 验证

`tests/integration.cjs` 使用隔离的临时数据和 Edge 浏览器，验证新建/改名、双语文字、移动/缩放/旋转、独立手机布局、透明图/GIF/MP4 上传、图层拖放/隐藏/锁定、删除与撤销、多窗口同步与接管、资料与微信、视频播放/暂停、手机菜单、预览、完整项目恢复、版本与失败导入保护、离线网站导出和重启持久化。

在已安装 Playwright 与 Edge 的环境中运行 `node tests/integration.cjs`。测试不会修改实际 `data/`。

`tests/redesign.cjs` 另行使用隔离数据，核对六种首屏拖尾、暂停与清理、首页第三模块完整 3 秒停留、五类筛选、24 个详情页、放大查看/切图/缩放、手机布局、标题与分类编辑、新增项目，以及完整项目导入。

`tests/module-layout.cjs` 只读验证当前项目：五个文件夹的素材对应、源文件哈希、指定封面与 16:9 入口、四类作品顺序、详情布局保留、装帧原比例、1–6 图片/视频轮播、第四模块 14 个原框的尺寸及排布不变、标题字体颜色、中英文字溢出、手机显示、素材解码和编辑器素材列表。`.preview/check-current-export.cjs` 检查当前网站导出后离线浏览的比例、视频和固定框。
